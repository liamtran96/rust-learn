Open mistakes (Ch 1)

  • 🟡 Shadowing arithmetic chain — 5 → 6 → 12, not 10. Evaluate step by step.
  • 🔴 Type annotation ≠ type cast — let a: i32 = 100_i32 doesn't help. Use as at the +.
  • 🔴 Expressions vs statements — if/else is an expression. Last expression of a block (no ;) is its value.
  • 🔴 Keyword salad static const ... mut — pick one of let mut / const / static; mut goes between let and the name.
  • 🔴 loop is not match — no Ok()=> arms; loop { break value; } is itself an expression.
