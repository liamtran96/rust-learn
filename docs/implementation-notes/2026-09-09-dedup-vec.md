# Hand-written consecutive vector deduplication

## Goal

Complete Ch 2 exercise 5 by implementing the consecutive-duplicate behavior of
`Vec::dedup` without calling the standard `dedup` method. This also completes the
Week 3 hand-written split/dedup shipping milestone.

## Implementation flow

`dedup_in_place<T: PartialEq>` mutably borrows the caller's vector and walks it
from index 1. It compares the current element with its immediate predecessor,
removes the current element when equal, and otherwise advances the cursor.
After removal the cursor stays in place because the next element shifts into the
current position and still needs comparison.

```text
[1, 1, 2, 1, 2, 2] -> [1, 2, 1, 2]
```

The generic `PartialEq` bound permits equality checks for integers, string
slices, and other comparable element types. The implementation modifies the
existing vector and returns unit.

## Maintenance guidance and remaining risk

Add new cases as table-driven unit tests if the exercise grows. Repeated
`Vec::remove` calls shift later elements, so this learning implementation can be
quadratic for heavily duplicated vectors; that tradeoff is acceptable here but
should be revisited for production-scale data.
